## Idea

App updates, releases and roadmap notes, pinned to a board that looks and feels like a real cork notice board.

## Key decisions

- **CSS 3D transforms** with cork textures and lighting, instead of a WebGL scene.
- **Seed-based random tilt** per card plus spring animations, so the board feels organic but stays the same between visits.
- **Admin dashboard behind Basic Auth middleware** for publishing, updating and drafting notices, backed by Supabase Postgres.

## Stack

Next.js · Tailwind CSS · Framer Motion · Supabase
