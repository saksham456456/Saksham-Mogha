## Problem

Reading static text is a slow way to learn a new idea, and it is easy to drift off.

## Approach

Professor Byte writes each lesson onto an animated **HTML5 Canvas** blackboard, using fast LLM responses from **Groq**. Game mechanics keep you coming back:

- XP and levels, 16 badges and a daily learning streak
- An auto-generated three-question pop quiz after every lesson
- Fun facts, a glossary and mid-lesson "think about it" checkpoints
- A daily challenge topic

## Stack

Node.js · HTML5 Canvas · Groq API
