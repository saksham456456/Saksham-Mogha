## Idea

Brain-Spark turns cognitive training into short games that target memory, attention, problem-solving and mental agility.

## Features

- Several game modes, each targeting a different cognitive skill
- Progress tracking with statistics
- Daily challenges and streaks
- Adaptive difficulty
- Offline mode and an OLED-friendly dark theme

## Stack

Kotlin · Jetpack Compose + Material 3 · MVVM + Clean Architecture · Room · DataStore · Firebase Analytics · min SDK 24
