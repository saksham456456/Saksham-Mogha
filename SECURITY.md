# Security Policy

## Reporting a Vulnerability

Security is a fundamental consideration for this site and all applications developed by Saksham Mogha. If you discover a security vulnerability or potential threat in this website or any associated repository, please report it responsibly.

### Contact Method
Please report any vulnerabilities through the encrypted Contact Portal:
- **URL:** https://saksham-mogha.vercel.app/contact
- **Topic:** Select "Other" or "App support" and prefix the subject with `[SECURITY DISCLOSURE]`

Please include:
- A detailed description of the vulnerability.
- Steps to reproduce or proof-of-concept payload.
- Potential impact and affected endpoints or headers.

### Response SLA
- **Initial acknowledgement:** Within 48 hours.
- **Triage & Remediation:** Within 7 business days depending on severity.

### Out of Scope
- Denial of Service (DoS/DDoS) attacks against third-party providers.
- Social engineering attempts.
- Issues related to software versions without a reproducible impact.
